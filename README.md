# The Growth

The Growth is a robotic sculpture installation by Filipe Vilas-Boas and Douglas Cabel. A robot arm stacks replica gold bars (15 x 5 x 1 cm) into a tower on a 120 x 120 x 100 cm pedestal. As the tower rises it becomes unstable, it falls, and the robot starts again, fully autonomously. It is a loop about the myth of infinite growth.

For the time being, let's keep the playable features aside and go for a nice prototype in 3D, using the KUKA KR FORTEC model for the robot part. Please build the animated scene with the most realistic 3D rendering in the browser, with the ability for the visitor to turn around the piece live, zoom in and zoom out, while the animation plays.
